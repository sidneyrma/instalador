## 3) ONDE COLAR E DICAS DE USO ⚙️

| Onde | Como |
|---|---|
| **Chats individuais** | Claude.ai → ícone do perfil → **Personalização** → **Instruções para o Claude** → cole o prompt (versão longa ou curta) → salvar. Vale para TODOS os chats e para o Cowork. |
| **Projeto (Project)** | Crie um Projeto no Claude.ai → **Project instructions** → cole o prompt + **faça upload dos protótipos** (`prototipo_home.html`, `prototipo_evolucao.html`, `prototipo_anestesia.html`, `prototipo_devocional.html`, `guia_vendd.md`) como arquivos de contexto. Assim o Claude tem as páginas reais como referência visual. |
| **Claude Code (CLI)** | Use `claude` e o arquivo `CLAUDE.md` na raiz do projeto com o mesmo conteúdo (versão curta). |

**Dicas para extrair o máximo:**
- Peça sempre: *"gere 3 variações"* ou *"cite a seção do protótipo"* — o prompt já orienta o formato;
- Quando for testar anúncio, diga o **público-alvo** e o **orçamento** (o prompt manda o Claude perguntar, mas você ganha tempo informando);
- Mantenha o prompt **atualizado** quando mudar preços ou links (o erro nº 1 que encontramos na sua página era preço divergente — o prompt trava isso);
- A versão curta é melhor para o Claude "obedecer" com mais consistência; a longa dá mais contexto. Teste as duas e veja qual flui melhor.
