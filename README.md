# 📖 O Ouro das Palavras — Joseph Murphy

Livro digital sobre **o poder criador da palavra**, baseado nos ensinamentos de Joseph Murphy, formatado segundo a **ABNT NBR 6029** (Apresentação de livros e folhetos): Times New Roman 12, espaço 1,5, margens 3/2 cm, recuo 1,25 cm e sumário com paginação.

## 📚 Conteúdo da pasta `livro/`

| Arquivo | Descrição |
|---|---|
| **`O_Ouro_das_Palavras.docx`** | O livro em Word (formato ABNT) |
| **`O_Ouro_das_Palavras_previa.pdf`** | Versão PDF da diagramação |
| **`docs/index.html`** | Página web do livro (GitHub Pages) |
| `fonte_original.txt` | Transcrição original preservada |
| `build_livro.py` | Script que gera o `.docx` e o `.pdf` |
| `build_site.py` | Script que gera a página web |

> 🔒 **Sobre cópias:** a página web não oferece botões de download e aplica
> proteção leve contra cópia (seleção de texto, menu de contexto, clipboard
> e **impressão desabilitada** — tentar imprimir mostra apenas um aviso de
> direitos autorais). Ela é um **deterrente** — nenhuma página pública na web
> impede 100% a cópia (ver fonte `Ctrl+U`/DevTools `F12` sempre expõe o
> texto). Os arquivos originais `.docx`/`.pdf` ficam apenas na pasta `livro/`
> do repositório (não são servidos pelo site).
