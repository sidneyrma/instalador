3. Padrão de escrita

Este é o jeito de escrever para o público e para o autor.

Regras da Missão

Português do Brasil, com acentos.
Frase de gente: curta, clara, como conversa franca.
Prefira "você". Não use "sincera(o)", "bem-vind(o)a" nem pares com barra de gênero em texto novo.
Sem travessão (nem o longo, nem o médio) em copy nova, FAQ, botão, carrossel, WhatsApp ou explicação. Use vírgula, ponto ou dois pontos.
Sem depoimento inventado.
Sem cura pronta. A Missão oferece caminho, no ritmo de cada um.
A Palavra primeiro. Leitura grátis antes de falar de pagamento.

Escrita humanizada

Varie o tamanho das frases: misture curtas e diretas com outras mais longas.
Fuja do padrão robótico: sem estrutura previsível em todas as frases e sem conectivos genéricos ("além disso", "portanto", "em resumo", "vale ressaltar").
Sem marcas de IA: nada de aspas desnecessárias, listas em excesso ou tom de comunicado de imprensa.
Escreva como quem conversa com um amigo inteligente: claro e autêntico.

Quiz da família

A frase "minha casa" (versículo e pergunta) permanece, porque é da Palavra e do roteiro.
Sexualidade: um pingo. Ouça. Sem catálogo, sem ato, sem perguntar "você é o quê?".

Se uma IA anterior usou outro vocabulário, ignore. Use só o deste arquivo.

13. Como aplicar mudança no site

A pasta pública é /www/wwwroot/missaocomdeus.com.br/. O GitHub não é o ar.

Regras

No aaPanel, Terminal: só 2 linhas, digitadas.
Se o Terminal mostrar o nome do script entre colchetes azuis, não clique. Isso gera can't open file ... Errno 2. Digite o nome do .py.
Nunca use cat >> em HTML.
Envie o .py e os HTML que o script precisa antes de pedir para rodar.
O script faz backup sozinho. Se a string não for achada, não grava. A segunda execução avisa que já estava aplicado.
Não substitua o index.html nem o miolo de um livro inteiro no servidor. Isso apaga banner, quiz, enquete e player.
Rode nginx -t antes de recarregar o Nginx.
Não mude URL de API nem webhook da Laura.
Não publique overlay no YouTube.

Passo a passo

Backup automático no script.
Subir o .py e o HTML necessário.
Duas linhas no Terminal:
cd /www/wwwroot/missaocomdeus.com.br
python3 NOME_DO_SCRIPT.py
Conferir no ar, no celular e no notebook, não só no painel sem internet.
